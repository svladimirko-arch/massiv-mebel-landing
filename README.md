# МАССИВ — лендинг мебельной мастерской

Одностраничный продающий сайт по заданию: https://www.fl.ru/projects/5529789/nado-sdelat-sayt-dlya-mebelnoy-kompanii.html

**Демо (GitHub Pages):** https://svladimirko-arch.github.io/massiv-mebel-landing/
**Репозиторий:** https://github.com/svladimirko-arch/massiv-mebel-landing

В папке лежит файл `отклик.md` — готовый краткий отклик на задание,
и ярлык `Открыть сайт.lnk` — быстрый открыватор `index.html` в браузере.

## Структура — ровно 4 блока

1. `#hero` — главный экран с анимацией по эталону `C:\Users\svlad\OneDrive\Документы\Стройка\site`:
   прелоадер с прогрессом, появление текста по строкам (GSAP timeline), наезд фона, параллакс,
   счётчики, пульсирующий бейдж, бегущая строка, магнитные кнопки.
2. `#about` — о нас: фото цеха с параллаксом, преимущества, CTA.
3. `#portfolio` — 5 работ (максимум по заданию), клик открывает lightbox.
4. `#contacts` — контакты-заглушки и форма заявки (отправка тоже заглушка).

Шапка, прелоадер, бегущая строка, лайтбокс и подвал — декоративные/служебные элементы,
не считаются смысловыми блоками.

## Файлы

- `index.html` — разметка
- `assets/css/style.css` — стили (тёмный графит + тёплый дуб, Unbounded/Manrope)
- `assets/js/main.js` — GSAP + ScrollTrigger, прелоадер, меню, форма, лайтбокс
- `assets/img/` — 7 изображений, сгенерированных локальным приложением Qwen
- `tools/qwen-cdp.mjs`, `tools/generate-images.mjs` — скрипты генерации картинок через Qwen CDP
